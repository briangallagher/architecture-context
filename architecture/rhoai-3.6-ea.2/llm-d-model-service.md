## Purpose

**Short**: Reconciles namespaced `ModelService` resources into model-serving workloads, services, routing resources, and supporting RBAC.

**Detailed**: The controller manages the desired state for a base model. A `ModelService` can select a BaseConfig ConfigMap and override its values through templating and semantic merging. Depending on the configuration, reconciliation creates prefill and decode Deployments and Services, an endpoint-picker Deployment and Service, ServiceAccounts and RoleBindings, and Gateway API InferenceModel, InferencePool, and HTTPRoute resources.

The controller uses Kubernetes owner/reference and namespace context to map child changes back to their `ModelService`. It also mirrors workload readiness into the custom resource status. The analyzed checkout is deprecated upstream; its README states that the core functionality moved to an llm-d Helm chart proposal and points continued development to `llm-d-incubation/llm-d-modelservice`.

## Architectural Analysis

This is a controller-runtime operator with a single manager Deployment and a namespaced custom-resource API. The `ModelService` is the source of truth for a complete inference stack: configuration is rendered from a BaseConfig plus per-model overrides, then materialized as Kubernetes resources. The controller watches both the primary resource and the resulting Deployments, Services, RoleBindings, ConfigMaps, HTTPRoutes, InferenceModels, InferencePools, and ServiceAccounts, giving it a broad reconciliation surface.

The release configuration exposes secure metrics on port 8443 and health probes on port 8081, while the default Prometheus example explicitly skips certificate verification. Secure metrics authentication and cert-manager certificate mounting are conditional configuration paths rather than uniformly enabled behavior. The Dockerfile builds with `CGO_ENABLED=0` and packages the binary in UBI9, so this branch does not establish the dynamic-linking FIPS requirements expected by check-payload. The repository’s deprecation status is an operational risk for RHOAI consumers.

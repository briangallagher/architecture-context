## Purpose

**Short**: Reconciles model-serving resources, publishes KServe serving-runtime templates, injects serving-related pod configuration, and exposes a Gateway API discovery service.

**Detailed**: `odh-model-controller` is a controller-runtime manager that watches and reconciles KServe inference resources, Gateway API resources, platform configuration, Secrets, Pods, ConfigMaps, NVIDIA NIM Accounts, and monitoring resources. It manages serving-runtime definitions and supporting authorization, networking, monitoring, and storage configuration for model serving.

The repository also builds `model-serving-api`, a separate HTTPS deployment that discovers labeled Gateway resources and serves authenticated gateway metadata plus public static llm-d samples. Both binaries use the in-cluster Kubernetes API and are deployed from the same image build.

## Architectural Analysis

The component combines a broad, cluster-integrated reconciliation plane with a small API plane. The controller manager is leader-election capable, uses informer-cache transformations to reduce cached payloads, and conditionally switches to a webhook-only profile on xKS. Its controllers bridge KServe, Gateway API, Kuadrant, KEDA, Istio, Prometheus Operator, platform initialization CRs, and NVIDIA NIM configuration rather than owning a standalone datastore.

Serving runtimes are declarative Kustomize resources. The same runtime families are emitted in ordinary, `fast-1`, and `fast-2` variants across CPU, CUDA, ROCm, Gaudi, Spyre, MLServer, and OVMS images. This gives platform operators accelerator-specific choices while retaining a common KServe API contract.

Tenant isolation is primarily Kubernetes namespace isolation and namespace-scoped watches for user data connections and Account resources. Cluster-scoped `ClusterServingRuntime` objects and the controller's broad RBAC are intentionally shared platform infrastructure; access to individual inference objects remains delegated to Kubernetes RBAC and generated policies. The API server adds application middleware for gateway discovery, while its sample endpoint is explicitly unauthenticated.

## Purpose

**Short**: The ODH Dashboard provides the RHOAI web console, federated feature UIs and BFF APIs, while its embedded operator reconciles Dashboard and workspace resources.

**Detailed**: The repository is a monorepo containing the React host application, Node.js backend/API proxy, multiple Go BFFs, shared TypeScript packages, and the `dashboard-operator`. The web tier serves the SPA and module-federated remotes, forwards authenticated requests to Kubernetes and platform services, and applies user/admin authorization checks.

The operator manages the Dashboard custom resource and renders component resources into the configured application namespace. The repository also contains the Kubeflow workspace backend/controller pair, which manages namespaced workspaces and cluster-scoped workspace kinds. The resulting architecture spans cluster control-plane integration, namespace-scoped tenant access, Gateway API routes, and service-specific BFF integrations.

## Architectural Analysis

This is a composite platform surface rather than a single runtime. The frontend host and Node backend form the user-facing shell; Go BFFs provide separately built feature backends and proxy calls to Kubernetes, model-serving, registry, MLflow, MaaS, evaluation, agent, and external AI services. Module Federation allows feature packages to be delivered independently while retaining a common authenticated backend boundary.

The dashboard operator is a controller-runtime manager with a broad cluster RBAC role. It reconciles the cluster-scoped `Dashboard` CR, creates or updates operand resources, and can manage Gateway API routes, OpenShift routes, RBAC, network policy, workloads, and platform configuration. The workspace controllers add a namespaced `Workspace` API and cluster-scoped `WorkspaceKind` API. This breadth is operationally powerful but makes least-privilege review and cross-namespace cleanup important risks.

The analyzer found no component ingress objects in this checkout, although source and RBAC evidence show Gateway API/HTTPRoute integration and the deployed dashboard endpoint is protected by `kube-rbac-proxy`. Ingress ownership is therefore split between this repository's operand reconciliation and the platform gateway infrastructure.

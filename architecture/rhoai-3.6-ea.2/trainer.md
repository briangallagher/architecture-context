## Purpose

**Short**: Kubeflow Trainer provides Kubernetes APIs and controllers for distributed AI training jobs and their runtime definitions.

**Detailed**: The controller watches TrainJob, TrainingRuntime, and ClusterTrainingRuntime resources, validates and defaults them through admission webhooks, and materializes distributed workloads. It integrates with JobSet, Volcano, and scheduler plugins for replicated and gang-scheduled training, and can create per-job NetworkPolicies.

The repository also ships Python dataset/model initializer images, framework-specific runtime images, and a Rust data-cache service. The RHOAI manager image uses the Konflux-specific FIPS build path and a digest-pinned UBI minimal PQC runtime image.

## Architectural Analysis

Trainer is a controller-runtime operator with a shared manager binary serving health, metrics, status, and admission-webhook surfaces. TrainJob is the namespace-scoped user-facing entry point; TrainingRuntime is namespace-scoped, while ClusterTrainingRuntime provides reusable cluster-scoped runtime definitions. Reconciliation expands a TrainJob into JobSet or scheduler-plugin/Volcano resources and applies runtime-specific framework plugins such as MPI, JobSet, Volcano, and co-scheduling.

The design separates control-plane policy from training data-plane containers. The manager uses a mounted webhook certificate, non-root/read-only container security settings, and Kubernetes RBAC. RHOAI adds network policy reconciliation and OpenShift TLS-profile handling. Namespace scoping and same-namespace runtime references provide the principal tenant boundary, but the manager's cluster-wide permissions and ClusterTrainingRuntime API require platform RBAC to prevent cross-tenant access.

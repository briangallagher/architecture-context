## Purpose

**Short**: Provides namespace-aware data-connection metadata, credentials, readiness checks, and connector-backed data access for RHOAI.

**Detailed**: data-connect-hub combines a Go controller-runtime manager with Rust REST and Arrow Flight services. The controller reconciles `DataConnectService`, `InitDataConnection`, and `InitDataConnectionType` resources and creates or updates service deployments, accounts, routing, RBAC, secrets, and network policies.

The REST service manages connection and connection-type metadata and exports credentials from Kubernetes Secrets. The Flight service serves ingestion/query operations through configurable PostgreSQL, SQLite, S3, Milvus, Elasticsearch, Neo4j, and URI connectors. PostgreSQL stores the metadata as JSON and applies tenant filters; a configured global tenant supplies shared connection types.

## Architectural Analysis

The component is a control-plane/data-plane bundle. A namespaced `DataConnectService` is the configuration anchor; the controller projects it into service deployments and supporting Kubernetes resources. REST is exposed behind a `kube-rbac-proxy` TLS sidecar, while Flight terminates TLS in the Rust service and exposes Arrow Flight over gRPC. A shared Gateway API `HTTPRoute` sends REST paths to `rest-service:8443` and Flight paths to `flight-service:8443`.

Tenant identity enters REST requests through `x-tenant-id`. The service authenticates bearer tokens with Kubernetes TokenReview and authorizes operations through namespace-scoped SubjectAccessReview. Metadata queries additionally constrain rows by `tenant_id` and permit the configured global tenant for connection types. This is a layered model, but the checked-in service NetworkPolicies currently allow all ingress and egress, leaving traffic isolation to RBAC, service configuration, and the platform gateway.

The Konflux controller build explicitly enables `CGO_ENABLED=1` and `GOEXPERIMENT=strictfipsruntime`; the Rust images use digest-pinned UBI minimal PQC runtime images and install rustls’ AWS-LC crypto provider. Cargo and Go dependency locks are present, as is an RPM lock, while no `artifacts.lock.yaml` or checked-in Hermeto `cachi2.env` was found.

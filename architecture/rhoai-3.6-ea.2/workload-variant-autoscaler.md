## Purpose

**Short**: A Kubernetes controller that performs intelligent autoscaling for inference workloads using Prometheus metrics, workload state, and optional GPU/resource-balancing strategies.

**Detailed**: The controller-manager watches ConfigMaps, HorizontalPodAutoscalers, InferencePools, and optionally KEDA ScaledObjects. It collects workload and inference metrics, applies saturation/queueing models and configuration, and updates workload scale targets. The coordinator and controller packages also support scale-to-zero and resource-aware rebalancing paths.

The component runs as a non-root, leader-elected Go controller with a health server on port 8081 and a TLS-protected controller-runtime metrics server on port 8443. It integrates with the Kubernetes API, Prometheus, KEDA, the Gateway API inference extension, and Kubernetes workload resources. Deployment is provided by kustomize bases with cluster-scoped and namespace-scoped overlays.

## Architectural Analysis

The design is a control-plane autoscaler rather than a serving data plane. A single controller-manager process combines reconcilers, metric collection, optimization, and actuators: it observes Kubernetes workload objects and inference-pool configuration, queries Prometheus, computes desired capacity, and writes scale changes through Kubernetes APIs. ConfigMap-backed configuration separates global optimization and saturation policy from workload resources; feature flags make coordinator and scale-to-zero behavior optional.

The same image supports cluster-scoped and namespace-scoped deployment modes. Cluster-scoped RBAC permits broad observation and mutation of workload scale resources, while namespace-mode overlays provide a narrower deployment option. Metrics are exposed through controller-runtime's authenticated HTTPS endpoint and scraped by a ServiceMonitor. Prometheus client TLS is configurable, including custom CA and client certificates, but the base ConfigMap currently defaults to skipping Prometheus certificate verification; this is a deployment security risk unless an overlay overrides it.

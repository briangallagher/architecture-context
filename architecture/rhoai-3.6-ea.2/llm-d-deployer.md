## Purpose

**Short**: Provides a monolithic Helm chart and quickstart manifests for deploying the llm-d distributed LLM inference stack on Kubernetes.

**Detailed**: The chart composes model-service resources, prefill/decode vLLM workloads, an endpoint picker, an inference gateway, optional Redis, telemetry, and sample application routing. It exposes configurable model artifacts, Hugging Face token references, GPU resources, gateway implementation, and listener/ingress settings through `charts/llm-d/values.yaml`.

The repository is a deployment package rather than an application implementation: it contains no Go/Python service source or container build files. The bundled `ModelService` CRD and templates provide the declarative contract, while the model-service controller, vLLM, inference scheduler/EPP, Gateway API implementation, and monitoring operators are external dependencies. The README marks the repository deprecated as of 2025-07-25 and directs new deployments to `llm-d-infra`.

## Architectural Analysis

This is a Helm composition layer with two principal paths. The model-service path creates a `ModelService`-driven inference topology with separate prefill and decode deployments, GPU requests, vLLM ports, an endpoint picker, and optional EPP metrics. The gateway path selects an Istio, kgateway, or GKE GatewayClass and can expose HTTP listeners through a NodePort or LoadBalancer-backed gateway and an optional Kubernetes Ingress. The chart therefore assembles control-plane configuration and data-plane workloads but does not own their reconciliation logic.

The default values favor a GPU inference deployment, a single prefill and decode replica, an Istio gateway class, and a sample model artifact from Hugging Face. Credentials are referenced through Kubernetes Secrets, but the default model URI and the optional sample Grafana configuration demonstrate that the quickstart is an example environment rather than a hardened production baseline. Cluster-scoped RBAC is used for ModelService access, metrics authentication, endpoint picking, and monitoring, so namespace-level tenancy requires careful binding and release configuration.

The repository is explicitly deprecated and its monolithic chart is no longer updated. Consumers should treat this checkout as historical deployment evidence and migrate to the modular `llm-d-infra` approach identified by the README.

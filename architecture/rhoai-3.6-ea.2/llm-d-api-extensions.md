## Purpose

**Short**: Adds opt-in vLLM endpoints that expose server configuration, device properties, and profiled KV-cache metadata to llm-d.

**Detailed**: The repository contains an independently installable Python package for vLLM. It registers three `vllm.endpoint_plugins` entry points, and vLLM attaches their FastAPI routers when the operator names the plugins in `VLLM_PLUGINS`. The package extends vLLM without forking or modifying vLLM core.

The configuration plugin reports model, KV-cache, scheduler, parallelism, feature, and optional KV-transfer settings. The device plugin obtains per-rank hardware information through vLLM `collective_rpc`, while the KV-cache plugin reports post-profiling capacity and, when supported by the vLLM build, attention-group metadata. Device and KV-cache responses are collected once at startup and cached for the server lifetime.

## Architectural Analysis

This is a library-style integration rather than a separately deployed workload. Its runtime boundary is the vLLM process: plugin entry points add read-only HTTP routes to the existing server, and the worker extension adds a `get_device_properties` method to the concrete vLLM worker class. The design keeps the feature opt-in and independently selectable, so installing the package has no effect unless the deployment configures `VLLM_PLUGINS`.

The three plugins deliberately separate data sources and engine requirements. Configuration works with the CPU-only render server because it uses `vllm_config` and does not touch an engine. Device and KV-cache introspection require an engine and return HTTP 503 on a render-only server. KV-cache group metadata is feature-detected with `hasattr`, preserving compatibility with vLLM versions that expose only capacity fields. The main security consideration visible in this checkout is that the HTTP routes have no repository-owned authentication or TLS layer; deployment-level protection is therefore required. Operator-controlled `kv_connector_extra_config` is returned as part of the configuration response and may contain sensitive data.

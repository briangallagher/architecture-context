## Purpose

**Short**: Argo Workflows provides Kubernetes-native workflow orchestration, execution, persistence, and API access for data-science pipeline workloads.

**Detailed**: The workflow-controller watches Argo workflow custom resources and creates and manages the Kubernetes pods and supporting resources required to execute them. `argoexec` is injected into workflow pods to implement executor behavior, artifact handling, and coordination with the Kubernetes API.

The Argo server exposes the workflow API and UI-facing HTTP/gRPC services, using Kubernetes RBAC and configurable server authentication. Workflows and most related objects are namespace-scoped, while ClusterWorkflowTemplate provides an explicitly cluster-scoped reusable template surface. Optional SQL persistence archives workflow state and artifacts by cluster, instance, and namespace.

## Architectural Analysis

This is a controller-plus-executor architecture rather than a standalone application: the controller owns reconciliation and scheduling decisions, while short-lived workflow pods run user-defined steps and use `argoexec` for lifecycle operations. The Argo server is a separate API deployment that fronts Kubernetes resources and optional SQL-backed archive storage.

RHOAI packaging supplies separate Konflux images for the executor and controller, both built from the same Go module and run as non-root users. The manifests support both namespace-install and cluster-install modes, allowing tenancy to be bounded by a managed namespace or extended across a cluster through explicitly broader RBAC.

The analyzed source enables secure server mode with TLS 1.2 as the default minimum, but its generated self-signed TLS configuration sets `InsecureSkipVerify=true`; this is a material application-level crypto risk and should not be interpreted as a FIPS assertion. The Konflux builds use static, pure-Go-style builds (`CGO_ENABLED=0`, `no_openssl`, and static external linking), so check-payload dynamic-linking compliance is not established by these Dockerfiles.

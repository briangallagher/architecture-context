## Purpose

**Short**: Reconciles TrustyAI evaluation, guardrails, service, and module resources into Kubernetes workloads and protected service endpoints.

**Detailed**: The operator manages the TrustyAI platform surface in a Kubernetes cluster. Its controllers reconcile EvalHub, LMEvalJob, GuardrailsOrchestrator, NemoGuardrails, TrustyAIService, and the cluster-scoped TrustyAI configuration resource, creating workloads, services, routes, configuration, service accounts, and RBAC needed by those resources.

EvalHub additionally provisions evaluation jobs and tenant-namespace access, while the guardrails controller discovers KServe InferenceServices and generates orchestrator configuration. Generated TrustyAI services are fronted by kube-rbac-proxy and TLS-enabled Services/Routes; observability is provided through Prometheus and OpenTelemetry integrations.

## Architectural Analysis

This is a multi-controller operator with both a platform/module manager and legacy/core controller entrypoints. The principal API model is namespaced for workloads and services, with a separate cluster-scoped `TrustyAI` configuration API. Several controllers create secondary resources dynamically, so the effective deployment includes more than the static `config/` bases.

The strongest tenancy boundary is Kubernetes namespace plus generated service accounts and RoleBindings. EvalHub explicitly discovers namespaces carrying the tenant label and creates per-tenant job credentials and access bindings. The operator itself retains cluster-wide permissions for reconciliation and can read or manage resources across those namespaces; application-level tenant policy therefore depends on the generated RBAC and controller logic.

Ingress is primarily OpenShift Route/VirtualService based in this checkout. Generated services use kube-rbac-proxy on 8443 with TLS certificates and proxy health on 9443. The analyzer found no Gateway API HTTPRoute or gRPC service definitions. Konflux Go builds enable CGO and `strictfipsruntime`; runtime TLS details are partly delegated to controller-runtime, kube-rbac-proxy, and generated configuration.
